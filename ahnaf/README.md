## Findings considered and rejected

- **SQL injection in `/api/hotspots` and the region CSV routes**: rejected. Box values are typed `float` by FastAPI and
  dates go through `datetime.date.fromisoformat` before reaching SQL (`server/kw/tools.py` `global_hotspots`, `hotspots_csv`).
- **Path traversal via region id**: rejected. `tools._read` rejects `/`, `\` and `..` and only opens `<name>.json`.
- **Alert email abuse**: rejected as a finding. `alerts.create` caps unconfirmed alerts per address (3) and alerts overall;
  the Host-header link issue is handled in plan 008.
- **3D home page weight (~6.5 MB models/textures)**: rejected. Already lazy-loaded (`App.tsx`: `lazy(() => import("./pages/Home"))`).
- **Add an ML fire forecast like some competitors**: rejected. It contradicts the project's guardrail (climatological
  outlook, never a forecast), and an unvalidated forecast would weaken the validity score. Plan 005's backtest is the honest alternative.
- **Year-to-year variance term in the calibration error**: deferred (plan 004 maintenance note). It changes every interval and needs its own validation.
- **Move the worldwide outlook (`outlook.py`) from Aqua to NOAA-20**: deferred. Worth doing after 003; Method page already states the limitation.

- **Code-scan findings rejected or deferred** (details in `docs/code-scan-review-2026-11-13.md`): S9, S10, B17, C2
  rejected; B9, B10, B13, B16, B18, B21–B24, C5, C6, C8 deferred until after the submission.
